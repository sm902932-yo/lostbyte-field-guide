Episode 01

Free prompt fixes that reduce made-up answers

Plain answer

Anthropic’s guide recommends giving the model permission to say “I don’t know”, having it answer only from documents you provide, asking it to extract direct quotes that support its claims, and retracting any claim it can’t support [Ep01 S8]. These work in any chatbot and cost nothing.

  • Add: “If you don’t know, say so.”
  • Paste the source and say: “Answer only from this text.”
  • Ask for the exact quote behind each claim; if there isn’t one, take the claim back.

Byte & Bit analogy

Version one: Bit asks with no guardrails and gets a polished, invented citation. Version two: Bit pastes the real article, asks for quoted evidence, and allows “I don’t know”. Same model, very different honesty. (Dramatized mock-up.)
